# ExamEase - Online Examination System

ExamEase is a simple and user-friendly Online Examination System developed using HTML, CSS, and JavaScript. This project allows students to log in, attend online multiple-choice examinations, and view their results instantly.

## Features

- Student Login
- Online Multiple Choice Questions (MCQ)
- Countdown Timer
- Previous and Next Question Navigation
- Question Palette
- Automatic Exam Submission
- Instant Result Calculation
- Pass or Fail Status
- Responsive User Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open the html folder.
5. Right-click on index.html.
6. Select Open with Live Server.
7. Enter your student name and ID.
8. Start the examination.

## How the System Works

1. Students enter their name and student ID.
2. The system displays the examination page.
3. Students answer the given MCQ questions.
4. The countdown timer tracks the remaining time.
5. Students submit their answers.
6. The result page displays the score, correct answers, wrong answers, and percentage.
